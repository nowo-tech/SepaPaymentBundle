# Backward-compatibility golden files

`golden-2.1.0/*.xml` are the pain.008 files written by the **v2.1.0** `DirectDebitGenerator` for the inputs in
`DirectDebitBcCases.php` (2.1 API only: two-decimal amounts, creditor BIC given), with `GrpHdr/CreDtTm` replaced by
`NORMALISED`. `tests/Integration/DirectDebitBackwardCompatibilityTest.php` checks that the current code writes the same
bytes with the default configuration.

They were generated by loading the classes of `git archive v2.1.0 src` ahead of the current ones (a PSR-4 autoloader
registered after `vendor/autoload.php`, so the v2.1.0 `Nowo\SepaPaymentBundle\` classes win) and calling
`(new DirectDebitGenerator(new IbanValidator(), null, false, null, null, new BicLookupService(new IbanValidator())))`
`->generate()` / `->generateFromArray()` on each case, then `DirectDebitBcCases::normalise()`.

Never regenerate them from a newer version: they are the reference.
